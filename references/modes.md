# 모드 판별

사용자가 "어떤 종류의 영상인지" 설명하지 않아도, 주어진 입력만으로 모드를 정한다. 모드가 인테이크 질문, 게이트 내용, 기본값을 결정한다. 판별 결과는 한 줄로 사용자에게 알리고(예: "참조 영상 + 단어 하나 → 모션 디자인 모드로 진행합니다"), 틀렸으면 사용자가 바로잡게 한다. 판별 자체를 질문하지 않는다.

## 판별표 (위에서부터 첫 번째로 맞는 행)

| 입력 신호 | 모드 | 대표 예 |
|---|---|---|
| 참조 영상(mp4/URL)이 있고 **제품·브랜드 소재가 거의 없음** (단어, 문구, 이름 하나 정도) | `motion` | 키네틱 타이포 쇼릴, 모션 디자인 인트로, 로고 스팅, 타이틀 시퀀스 |
| 정적 이미지·카드 여러 장 / 포스터 / 안내문을 "영상으로" | `info` | 카드뉴스 → 키오스크·사이니지 루프, 행사 안내, 인포그래픽 |
| 제품 URL, 스크린샷, 앱 녹화, 기능 설명 | `launch` | 런치 영상, 기능 소개, 프로모 |
| 세로(9:16) + 20초 이하 + SNS 언급 | `social` | 릴스/쇼츠/틱톡용 훅 영상 |
| 판단 불가 | `launch` 로 시작하되 첫 질문에 "참조 영상이 있으면 주세요" 포함 | |

한 입력이 여러 모드에 걸치면(예: 제품 소개인데 참조가 키네틱 타이포 쇼릴) **소재로 모드를 정하고 참조로 스타일을 정한다.** 제품 소재가 있으면 `launch`, 스타일 스펙은 참조에서 가져온다.

## 모드별 차이

| | `launch` | `motion` | `info` | `social` |
|---|---|---|---|---|
| 인테이크 필수 | 제품, 스크린샷, 브랜드 | **참조 영상 + 들어갈 문구** | 원본 이미지/문구, 설치 환경(화면 크기·시청 거리) | 훅 한 줄, 소재 |
| 인테이크 기본값 | 20–40s, 16:9 | **참조와 같은 길이·비율·fps** | 루프, 무음, 장면당 6–8s | 9:16, 15s, 첫 1초 훅 |
| G1 참조 | whatships에서 후보 제시 → 선택 | **주어진 참조가 곧 G1** (분석만) | 원본 자료가 스타일 기준 | whatships 또는 주어진 참조 |
| G2 방향 | 스토리보드 3안 중 선택 | **샷 리스트 승인** (참조가 방향이므로 3안 불필요) | 스토리보드 3안 | 훅 3안 |
| G3 정지 프레임 | 장면당 1장 | **샷당 1장 + 참조 동일 시점과 나란히** (`snapshot --against`) | 장면당 1장 | 장면당 1장 |
| G4 노트 | 카메라 어휘 | 카메라 어휘 + **참조 대비 차이 목록을 에이전트가 먼저 제시** | 가독성(거리) 중심 | 첫 1초 강도 |
| 사운드 | 선택 | **참조에 음악이 있으면 비트 동기화 필수** (참조 음악은 싱크 분석용, 결과물엔 사용자가 준 음원 또는 무음) | 기본 무음 | 음악 필수 |
| 핵심 문서 | director-notes, quality-bar | **shot-decomposition, motion-craft** | quality-bar(가독성), gotchas | motion-craft(훅) |

## `motion` 모드 최소 입력

참조 영상 + 문구 하나면 시작한다. 다음은 **묻지 않고** 참조에서 추론한다: 색, 폰트 계열, 길이, 비율, 컷 리듬, 모티프, 음악 유무. 사용자에게 묻는 건 최대 2개:

1. 참조의 어떤 문구를 무엇으로 바꿀지 (예: 참조의 "MOTION / TYPE / CLAUDE" → 사용자 문구). 사용자가 단어 하나만 주면 그 단어를 최종 락업에, 참조의 반복 단어 자리에는 같은 단어 또는 관련 단어를 제안.
2. 음악: 참조와 같은 느낌의 음원이 있는지. 없으면 무음 렌더 + 참조 음악으로 컷 타이밍만 맞춘 버전(로컬 확인용)을 만든다고 알린다.

## `info` 모드 최소 입력

원본 자료 + 설치 환경. 화면 물리 크기(mm/인치)가 주어지면 비율과 해상도를 계산한다(예: 528×297mm → 16:9 → 1920×1080). 시청 거리 1–3m 기준 본문 최소 34px, 헤드라인 80px 이상.

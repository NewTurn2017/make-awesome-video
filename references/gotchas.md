# 실전에서 확인된 함정

실제 제작에서 부딪힌 것만 적는다. 새로 부딪히면 여기에 추가한다.

## 소재 준비

- **`npx hyperframes remove-background`는 사람 분리 모델이다.** 캐릭터 인형, 마스코트, 소품, 손+물체는 제대로 분리되지 않는다(사람 형태만 남기거나 배경을 남김). 대신:
  1. `gpt-image` 스킬로 편집: "이 캐릭터만 그대로, 완전한 단색 #FF00FF 배경 위에, 그림자·바닥·텍스트 없이"
  2. 마젠타 크로마키: `alpha = 1 - clip((min(R,B) - G - 60) / 80, 0, 1)` + 가장자리 마젠타 스필 제거 → 투명 PNG → `getbbox()`로 크롭
  3. 원본에서 잘려 있던 부분(예: 하반신)은 AI가 채운 것이므로 **브랜드 확인 필요**라고 사용자에게 알린다.
- **흰 로고가 단색 배경 위에 있을 때**: 배경색 채널 차이로 알파를 만든다 (예: 파랑 배경이면 R 채널 `(R-80)/(250-80)`). 모델 불필요.
- **텍스트가 박힌 키비주얼을 와이드로**: `gpt-image` 편집으로 "모든 텍스트·로고 제거, 좌우 자연스럽게 확장, 헤드라인 들어갈 쪽은 차분하게". 원본 비율 이미지는 cover로 늘리지 않는다.
- **소재를 이미지 생성으로 만들 때 (실사 소재가 없는 브랜드 영상 등):**
  - 모든 컷에 **같은 스타일 문장**을 앞에 붙여 배치로 생성한다 (예: "흑백 35mm 다큐멘터리, 고대비, 단일 하드 라이트, 필름 그레인, 로고·글자 없음, 16:9"). 컷마다 스타일을 따로 쓰면 톤이 흩어져 AI 티가 난다.
  - 컷마다 **카피가 들어갈 여백 위치**를 프롬프트에 적는다 ("피사체는 오른쪽 3분의 1, 왼쪽은 어두운 여백"). 여백 없이 생성하면 G3에서 카피가 피사체를 덮는다.
  - 실존 브랜드 스펙 광고면 제품도 **로고 없는 범용 제품**으로 생성한다 (상표·디자인 문제). 브랜드 요소는 HTML/SVG로 얹는다.
  - 생성 결과가 1920px 미만이면(예: 1672×941) `ffmpeg -vf scale=1920:1080:flags=lanczos`로 올리고, 푸시 인은 1.08배 이하로 제한한다.
- **음원을 생성할 때:** 한 번에 2곡 이상 받아 초당 음량 곡선(RMS)으로 드롭 위치를 비교해 고른다. `npx hyperframes beats`의 자동 BPM은 틀릴 수 있다(실측 120인데 178 "uncertain"). 강한 비트 간격으로 박자·마디를 직접 확인하고, 구간(인트로 / 빌드 / 드롭 / 클러스터 / 락업)과 강박 시각을 `storyboards/music-map.md`로 적은 뒤 스토리보드의 컷을 그 시각에 맞춘다.
- **폴라로이드·카드처럼 틀이 있는 사진**: 틀째 누끼 따지 말고 안쪽 사진만 크롭하고 틀은 HTML로 다시 만든다 (손글씨 캡션은 로컬 폰트, 예: Nanum Pen Script).

## 컴포지션

- **외부 JS 파일에 `</script>` 문자열을 절대 쓰지 않는다 (주석 포함).** HyperFrames는 컴파일 때 스크립트를 인라인하므로 그 문자열이 태그를 닫아버리고, 나머지 코드가 화면에 글자로 찍힌다. 증상: 스냅샷에 소스 코드가 텍스트로 보임, `Fonts: 0 loaded`.
- **빌드 중에 글자 위치를 재는 코드(커서, 마침표 위치, fitWidth)는 폰트 로드 후에.** `document.fonts.load('900 300px "Font"').then(build)` 안에서 타임라인을 만들고 마지막에 `window.__timelines[...] = tl` 등록 (hyperframes-core: 비동기 빌드는 등록만 마지막이면 허용).
- **여러 줄 카피는 줄마다 `fitWidth`를 따로 건다** (줄 길이가 달라 줄마다 크기가 달라지는 "양끝 맞춤 스택"이 된다). kit `fitWidth`는 요소 박스가 아니라 텍스트 자체(Range)를 재므로 block 줄에도 맞다. 직접 잴 때 block 요소의 `getBoundingClientRect().width`를 쓰면 부모 폭이 잡혀 둘째 줄부터 작아진다.
- **`fitWidth`는 애니메이션의 최종 축 상태로 잰다.** 굵기·너비를 트윈하는 단어를 wdth 84로 맞춰 놓고 wdth 110으로 끝내면 화면 밖으로 넘친다. 끝 상태 값을 CSS 기본값과 같게 두거나, 끝 상태로 잰다.
- **의도된 겹침은 `data-layout-allow-overlap`.** 레이어 돌출 글자, 행간이 좁은 두 줄 분할 등. kit `depthText`는 자동으로 붙인다. 없으면 `check`가 `content_overlap` 오류를 낸다. **속성은 겹치는 텍스트 요소 각각에** 붙인다. 행간 0.84로 쌓은 단어 스택은 컨테이너에만 붙이면 계속 실패하고, 단어 span마다 붙여야 통과한다.
- **장식용 글자도 대비 검사 대상이다.** 돌출 뒷면 레이어처럼 어둡게 둔 글자도 배경 대비 3:1(큰 글자)을 넘겨야 `check`가 통과한다. 개별 제외 방법이 없다. 예: #101010 배경이면 뒷면 #707070 이상.
- **t=0 상태는 타임라인 `set`이 아니라 요소 인라인 스타일로.** GSAP는 렌더러가 t=0으로 되감을 때 위치 0의 zero-duration `set`을 되돌린다. 첫 프레임이 "덮여 있음"(루프 시작)처럼 CSS 기본값과 다른 상태여야 하면 빌드 때 `el.style`로 직접 설정한다. kit `ringWipe.coveredAt0()`이 이렇게 한다. 증상: 스냅샷 0s만 이상하고 0.03s부터 정상, `loop_seam.py` 실패.
- **비트마다 사진을 갈아 끼우는 컷 연타:** 사진을 한 장면 안에 전부 겹쳐 두고, 첫 장을 뺀 나머지는 인라인 `style="opacity: 0"`, 각 비트 시각에 `tl.set(img, {opacity: 1}, t)`. 나중 DOM이 위에 오므로 이전 사진을 끌 필요가 없다. 컷마다 `scale 1.06→1` 펀치를 얹으면 스트로브 느낌이 난다.
- **스택 순서:** 나중에 들어오는 전면 패널(`mak-panel`)이 같은 장면의 글자를 덮을 수 있다. 패널 위에 남아야 할 글자에는 `z-index`.

- **마스크(`mask-image`)로 가리는 오버레이는 `check`의 레이아웃 검사가 "불투명 요소가 텍스트를 가림"으로 오탐한다.** 오버레이가 쉬는 동안 `visibility: hidden`으로 숨긴다 (kit `ringWipe`는 자동 처리). 숨김은 실제 렌더에도 이롭다.
- 장식 링·큰 원이 화면 밖으로 나가는 건 의도이므로 `data-layout-allow-overflow`를 붙인다.
- 액센트 색 텍스트를 같은 계열 배경 위에 두면 대비 실패(예: 민트 #00FFD7 on 블루 #4C7DFF = 2.86:1). `check`의 Contrast 결과를 따른다.
- 한 파일에 장면 8개를 `<section class="clip">`으로 두면 `nested_structure_needs_subcomposition` 경고가 뜬다. 렌더에는 문제없음. Studio에서 편집할 사람이 있으면 장면별 서브 컴포지션으로 나눈다.
- `ls`가 걸리는 셸(eza 별칭 등)이 있다. 파일 확인은 `find`나 `python3`로.

## 루프

- 루프 영상은 첫 프레임과 마지막 프레임이 같아야 한다. 커버 전환으로 끝낼 때는 **마지막 프레임 시점(길이 - 1/fps)에 커버가 완료**되도록 끝을 0.1s 앞당긴다. 검증: `python3 {baseDir}/scripts/loop_seam.py renders/out.mp4` (평균 픽셀 차 < 1이면 통과).

## 렌더

- `--output`은 현재 작업 폴더 기준 경로.
- 워커 수 경고(`V8 heap`)가 나오면 `--workers 5` 또는 `NODE_OPTIONS=--max-old-space-size=8192`.
- `snapshot`을 다시 실행하면 `snapshots/` 폴더가 새로 채워져 이전 프레임이 사라진다. G3 비교용으로 남길 프레임은 다른 폴더로 복사해 둔다.
- 렌더 결과 검수는 `snapshot`이 아니라 실제 MP4에서 프레임을 뽑아 본다 (`ffmpeg -ss <t> -i renders/draft.mp4 -frames:v 1`, 여러 장은 `tile=4x4`). 슬램 착지 직후, 휩 중간, 드롭 컷 직후, 마지막 프레임을 포함한다.
- ffmpeg 빌드에 따라 `drawtext` 필터가 없다. 프레임 라벨은 PIL로 (analyze_ref.sh `--fps`가 처리).

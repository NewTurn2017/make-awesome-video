# 감독 노트: 카메라 어휘 → 코드 변경

모호한 노트("더 좋게", "더 역동적으로", "좀 더 프로처럼")는 랜덤 변경을 만든다. 카메라 어휘는 정확한 변경을 만든다. 이 표로 노트를 **파라미터 변경**으로 번역하고, 변경 내역을 장면·파일·값으로 보고한다.

## 번역 규칙

- 배속 노트 "Nx로 느리게/빠르게": 해당 트윈 duration에 `1/N`을 곱한다. "줌을 0.7x로 느리게" = 줌 duration × (1/0.7) ≈ ×1.43. 이동 거리/스케일 값은 그대로. 장면 길이가 부족해지면 장면 길이를 늘릴지 사용자에게 알린다.
- 범위 없는 노트("모든 줌")는 전 장면에 적용하고 적용 목록을 보고한다.
- 노트 하나당 변경 하나. 노트에 없는 것은 건드리지 않는다.
- 해석이 둘 이상이면 고르게 한다 (예: "여기 더 강하게" → 스케일 증가? 이징 강화? 컷 추가?).

## 카메라 & 편집 어휘

| 노트 | 의미 | 기본 파라미터 (시작점) | 관련 HyperFrames 블록 |
|---|---|---|---|
| 푸시 인 (push in) | 대상 쪽으로 천천히 다가감 | scale 1.00→1.06–1.12, 샷 길이 전체, ease out (`power2.out`) | `push-in`, `ui-focus-zoom` |
| 풀 아웃 / 풀 백 리빌 | 멀어지며 맥락 공개 | scale 1.3→1.0, ease in-out | `pull-back-reveal`, `parallax-unzoom` |
| 크래시 줌 / 스냅 줌 | 순간 급줌 | 0.15–0.25s, scale ×1.5–2, `expo.out`, 모션 블러 | `cinematic-zoom`, `zoom-through-transition` |
| 하드 컷 | 트랜지션 없이 다음 장면 | 트랜지션 제거, 컷 지점을 비트/동작 끝에 맞춤 | — |
| 매치 컷 | 모양/위치가 이어지는 컷 | 두 장면의 핵심 요소 위치·크기 일치 후 하드 컷 | `match-cut`, `type-match-cut`, `text-match-cut` |
| 휩 팬 (whip pan) | 빠른 좌우 스와이프 전환 | 0.25–0.35s, x ±100vw, 방향성 모션 블러 | `whip-pan`, `whip-pan-cut` |
| 랙 포커스 | 초점 전환 | 앞 레이어 blur 0→8px, 뒤 레이어 8→0px, 0.6s | `rack-focus`, `focus-rack`, `focus-blur-resolve` |
| 패럴랙스 | 깊이감 있는 레이어 이동 | 레이어별 이동량 비율 1 : 0.6 : 0.3 | `parallax-zoom`, `camera-rig-depth-stack` |
| 돌리 줌 | 배경만 늘어나는 느낌 | 전경 고정, 배경 scale 반대 방향 | `camera-dolly-zoom` |
| 오빗 / 틸트 | 3D 회전 | rotateY ±8–15°, perspective 1200px | `tilt-card`, `split-tilt-cards` |
| 홀드 (hold) | 멈춰서 읽게 함 | 최종 상태 유지 +0.5–1.0s | `drift-hold` |
| 스태거 | 요소들이 시차 두고 등장 | 30–60ms 간격 (타이포), 80–120ms (카드) | `stagger-cascade`, `per-word-rise` |
| 슬램 | 강한 착지 | scale 1.3→1.0, 0.2s, 착지 순간 미세 셰이크 | `headline-slam`, `shutter-slam` |
| 온 비트 | 음악 비트에 컷/액센트 | `npx hyperframes beats` 결과 타임스탬프에 스냅 | `beat-accent`, `beat-freeze-cut` |
| 프리즈 프레임 | 동작 중 정지 + 주석 | 0.5–1.5s 정지, 주석 오버레이 | `freeze-frame-dressing` |
| 라이트 스윕 | 표면을 지나가는 빛 | 45° 그라데이션 띠, 0.8s | `light-sweep-pass`, `gloss-sweep` |
| 버튼 프레스 | 커서가 버튼을 누름 | 커서 이동 0.5s → scale 0.96 → 리플 | `simulated-cursor`, `press-ripple`, `gesture-tap` |

## 타이밍 & 이징 어휘

| 노트 | 변경 |
|---|---|
| "더 스냅피하게" | ease out을 `power2`→`expo`/`power4`로, duration ×0.7 |
| "더 부드럽게 / 차분하게" | duration ×1.3–1.5, `sine.inOut`, 오버슈트 제거 |
| "바운스 빼" | `back`/`elastic` → `power3.out` |
| "숨 쉴 틈" | 장면 끝 홀드 +0.5s, 텍스트 등장 후 0.8s 이상 유지 |
| "리듬이 늘어짐" | 가장 긴 샷부터 20–30% 트림, 크로스페이드 → 하드 컷 |
| "너무 정신없음" | 동시에 움직이는 요소를 1–2개로, 나머지는 정지 |

## 레이아웃 & 타이포 어휘

| 노트 | 변경 |
|---|---|
| "타이포 더 크게/대담하게" | 헤드라인 크기 ×1.25–1.5, 굵기 +100, 자간 -1~-3% |
| "여백" | 안전 영역 마진 6%→10%, 요소 수 줄이기 |
| "중앙 말고" | 좌측 정렬 + 그리드 컬럼 기준 배치 |
| "위계" | 한 프레임에 강조 1개, 나머지 크기/대비 낮춤 |

## 오디오 어휘

| 노트 | 먼저 할 일 | 변경 |
|---|---|---|
| "저 휘시 너무 커 / 거슬려" | 음악 전용 렌더의 같은 시점을 들려 달라고 한다 (스네어·라이저가 휘시처럼 들림) | 효과음이면 대역 내 +2–3dB로, 150Hz 아래가 많은 소스는 교체 ([audio.md](audio.md)) |
| "아무것도 안 들려" | 그 시점 음악이 데드 스톱·성긴 구간인지 확인 | 이벤트별 바닥값 적용, 음악 전체 −10% |
| "음악이 안 맞아" | 시청자(누가 보나)와 장르 대조 | 2–3개 옵션을 같은 음량으로 붙여 제시 |
| "싱크가 안 맞아" | 컷 시각과 실제 온셋 비교 (샘플 앞 여백 확인) | 컷 사이 스트레치 ≤0.5%, 도착을 비트에 |
| "작은 소리가 빠졌어" | 기계적 움직임 목록 작성 | 실제 녹음 마이크로 사운드, 각각 음악 피크 이하 |

한 라운드에 하나만 바꾸고 타임스탬프로 이름 붙인다.

## 노트를 받았을 때 보고 형식

```
노트: "모든 줌을 0.7x로 느리게"
적용:
- scene-02.html push-in: 2.0s → 2.86s
- scene-05.html ui-focus-zoom: 1.2s → 1.71s (장면 길이 3.0s → 3.5s로 연장 필요 — 연장함)
재렌더: renders/v3-draft.mp4
확인: snapshot 2.5s, 11s 확인 완료
```

## 에이전트가 먼저 제안할 노트 (사용자가 막막할 때)

첫 렌더를 보고 다음 신호를 찾아 카메라 어휘로 제안한다:

- 모든 게 페이드 인 → "텍스트는 마스크 리빌, 장면 전환은 하드 컷"
- 중앙 정렬 일색 → "좌측 정렬 그리드로"
- 정지된 UI 스크린샷 → "스크린샷에 느린 푸시 인 + 핵심 버튼에 커서 프레스"
- 모든 샷 길이가 같음 → "훅은 빠르게(0.6s), 데모는 길게(2.5s)"
- 끝이 흐지부지 → "로고에 슬램 + 1s 홀드 후 하드 컷 투 블랙"
- 무관한 장면이 연달아 슬라이드 인 → "장면 3의 카드를 장면 4 헤더 위치로 그대로 넘기기" ([motion-grammar.md](motion-grammar.md))
- 작은 카드가 빈 화면에 떠 있음 → "카드 1.6배, 화면 70% 차지하게 푸시 인"
- 정지 구간이 0.6초 넘음 (`frozen_time.sh`) → "해당 구간 3–5% 느린 푸시 또는 트림"

이 목록보다 5단계 전체 영상 크리틱의 상위 지적이 우선 근거다 ([critic-loop.md](critic-loop.md)).

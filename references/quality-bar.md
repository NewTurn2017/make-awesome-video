# 퀄리티 바: "싸구려로 읽히는" 신호

정지 프레임(G3)과 렌더 후에 스스로 검수한다. 걸리는 항목은 사용자에게 보여주기 전에 고치거나, 고칠 수 없으면 밝힌다.

## 기본값 냄새 (참조가 없을 때 에이전트가 돌아가는 곳)

- [ ] 모든 텍스트가 화면 정중앙에 있음
- [ ] 보라-파랑 그라데이션 배경
- [ ] 모든 요소가 opacity 0→1 페이드 인으로만 등장
- [ ] 모든 장면 길이가 같음
- [ ] 장면 전환이 전부 크로스페이드
- [ ] 이모지/일반 아이콘으로 기능을 설명

스타일 스펙이 명시적으로 요구하지 않는 한 위 항목은 결함이다.

## UI 표현

- [ ] 플레이스홀더 박스, 회색 막대로 된 가짜 텍스트, lorem ipsum 없음
- [ ] 버튼 높이·패딩·라운드가 한 시스템 안에서 일관됨 (4/8px 그리드)
- [ ] 실제 제품 스크린샷을 썼다면 해상도가 푸시 인 최대 배율을 견딤 (최대 scale × 출력 해상도 이하)
- [ ] 가짜 UI를 그렸다면 21st/shadcn 컴포넌트 기반이며, 실제 제품에 없는 기능을 보여주지 않음
- [ ] 커서가 보인다면 경로가 자연스러움 (직선 등속 이동 아님, ease in-out + 살짝 곡선)

## 타이포

- [ ] 브랜드 폰트가 실제로 로드됨 (시스템 폴백 폰트로 렌더되지 않음, 스냅샷으로 확인)
- [ ] 한 프레임에 서체 2종 이하, 굵기 3단계 이하
- [ ] 한 줄 텍스트 1.2초 이상 읽을 시간 (약 3단어/초 기준)
- [ ] 안전 영역 밖으로 잘린 글자 없음, 과부(한 단어 줄) 없음
- [ ] 한글 텍스트면 한글 폰트 지정 및 줄바꿈(`word-break: keep-all`) 확인

## 색 & 대비

- [ ] 브랜드 HEX를 그대로 사용 (근사치 아님)
- [ ] 액센트 색은 강조에만
- [ ] 텍스트 대비 충분 (`npx hyperframes validate`/`check`의 contrast 경고 확인)

## 모션

- [ ] 스타일 스펙의 이징과 트랜지션 비율을 따름
- [ ] 동시에 움직이는 주요 요소 2개 이하
- [ ] 마지막 프레임이 로고/CTA로 1초 이상 홀드
- [ ] 음악이 있으면 주요 컷이 비트에 맞음

## 기술

- [ ] `npx hyperframes check` 에러 0
- [ ] 목표 해상도·fps·길이 일치 (`ffprobe`로 확인)
- [ ] 첫 프레임이 빈 화면이 아님 (썸네일로 쓰임)

# 퀄리티 바: "싸구려로 읽히는" 신호

정지 프레임(G3)과 렌더 후에 검수한다. 걸리는 항목은 사용자에게 보여주기 전에 고치거나, 고칠 수 없으면 밝힌다. 체크리스트를 빌더가 직접 채우는 것만으로는 부족하다. G4 전에는 새 크리틱이 같은 기준으로 판정한다 ([critic-loop.md](critic-loop.md)). **에러 0과 매끄러움은 "좋음"이 아니다.** 깨끗하지만 평범하고 비어 있고 느린 버전도 거절된다.

## 측정 (숫자로 확인하는 것)

| 항목 | 목표 | 방법 |
|---|---|---|
| 정지 구간 | 30초당 총 1초 이하, 락업/CTA 외 0.6초 넘는 홀드 없음 (`motion` 쇼릴의 의도된 정지 비트는 샷 리스트에 적힌 것만 예외) | `bash {baseDir}/scripts/frozen_time.sh renders/x.mp4 --ignore-tail <락업 길이>` |
| 음량 | 펀치 있는 영상 약 −14 LUFS, 차분한 영상 약 −16 ~ −19, true peak ≤ −1 dBFS | `bash {baseDir}/scripts/loudness.sh renders/x.mp4` |
| 다이내믹 | 에너지 있는 스코어 LRA 3 LU 이상, 차분한 스코어 1.5–3 LU (끝나기 전에 죽지 않게) | 같은 스크립트 |
| 효과음 대 음악 | 효과음 자기 대역에서 음악 대비 +3–4dB, 2–8kHz 상승 4dB 이하 | [audio.md](audio.md) "레벨" |
| 텍스트 대비 | 정착한 글자 전부 WCAG AA (전환 중 페이드 제외) | `npx hyperframes check`의 contrast |
| 브랜드 색 | 렌더된 배경을 크롭·평균해 브랜드 토큰과 일치 (3D 톤 매핑·인코딩이 색을 바꾼다) | 프레임 추출 후 픽셀 평균 |
| 결정성 | 같은 시점을 다른 seek 순서로 두 번 렌더해 같은 픽셀 | `snapshot --at 2,5`와 `--at 5,2`를 따로 찍어 같은 시각끼리 비교 |
| 첫 프레임 | 완성된 구도 (반쯤 들어온 단어 아님) | `ffmpeg -ss 0 -i x.mp4 -frames:v 1` |

## 기본값 냄새 (참조가 없을 때 에이전트가 돌아가는 곳)

- [ ] 모든 텍스트가 화면 정중앙에 있음
- [ ] 보라-파랑 그라데이션 배경
- [ ] 모든 요소가 opacity 0→1 페이드 인으로만 등장
- [ ] 모든 장면 길이가 같음
- [ ] 장면 전환이 전부 크로스페이드
- [ ] 이모지/일반 아이콘으로 기능을 설명

스타일 스펙이 명시적으로 요구하지 않는 한 위 항목은 결함이다.

## UI 표현

- [ ] 플레이스홀더 박스, 회색 막대로 된 가짜 텍스트, lorem ipsum 없음
- [ ] 버튼 높이·패딩·라운드가 한 시스템 안에서 일관됨 (4/8px 그리드)
- [ ] 실제 제품 스크린샷을 썼다면 해상도가 푸시 인 최대 배율을 견딤 (최대 scale × 출력 해상도 이하)
- [ ] 가짜 UI를 그렸다면 21st/shadcn 컴포넌트 기반이며, 실제 제품에 없는 기능을 보여주지 않음
- [ ] 커서가 보인다면 경로가 자연스러움 (직선 등속 이동 아님, ease in-out + 살짝 곡선)

## 타이포

- [ ] 브랜드 폰트가 실제로 로드됨 (시스템 폴백 폰트로 렌더되지 않음, 스냅샷으로 확인)
- [ ] 한 프레임에 서체 2종 이하, 굵기 3단계 이하
- [ ] 한 줄 텍스트 1.2초 이상 읽을 시간 (약 3단어/초 기준)
- [ ] 안전 영역 밖으로 잘린 글자 없음, 과부(한 단어 줄) 없음
- [ ] 한글 텍스트면 한글 폰트 지정 및 줄바꿈(`word-break: keep-all`) 확인

## 색 & 대비

- [ ] 브랜드 HEX를 그대로 사용 (근사치 아님)
- [ ] 액센트 색은 강조에만
- [ ] 텍스트 대비 충분 (`npx hyperframes validate`/`check`의 contrast 경고 확인)

## 모션

- [ ] 스타일 스펙의 이징과 트랜지션 비율을 따름
- [ ] 동시에 움직이는 주요 요소 2개 이하
- [ ] 마지막 프레임이 로고/CTA로 1초 이상 홀드
- [ ] 음악이 있으면 주요 컷이 비트에 맞음

## 구도 & 전환

- [ ] 빈 프레임 없음 (제목이 오기 전 빈 색 띠, 빈 필드 위 사진 한 장)
- [ ] 기능 비트에서 주 피사체가 화면의 60–85%
- [ ] 글자 충돌 없음, **전환 중간 포함**: 제목 위의 제목, 헤딩을 관통하는 글자, 와이프가 이어 붙인 두 제목
- [ ] 목록·행 간격이 균등함 (같은 행 높이, 같은 왼쪽 정렬선). 클라이언트가 바로 알아챈다
- [ ] 헤드라인·이미지·보조 행의 왼쪽 가장자리가 맞음
- [ ] 전환마다 넘겨지는 물체나 맞춘 방향이 있음. 무관한 슬라이드 인이 연속되지 않음 ([motion-grammar.md](motion-grammar.md))
- [ ] 핀·콜아웃이 가리키는 대상 위에 있고, 사진 라벨이 내용과 맞음
- [ ] 3D가 설계된 것으로 읽힘: 장난감 같은 틈, 떠 있는 부품, 텍스처 반복, 수직 하강 "판" 각도, 팝 없음 ([three-d.md](three-d.md))
- [ ] 소비자 대상이면 밝게. 어둡고 무거운 오프닝은 거절됐다 (브랜드가 요구하지 않는 한)
- [ ] 거의 검은 전환 프레임 없음 (폰에서 이야기가 사라진다)

## 사업 메시지 (소리 끄고 판정)

- [ ] 처음 보는 사람이 끝까지 보고 무엇을 하는 회사인지, 다음 행동 하나가 무엇인지 말할 수 있음
- [ ] 모든 주장이 사실이거나 컨셉으로 분명히 표기됨
- [ ] CTA가 폰 크기에서 1.5초 이상 읽힘

## 기술

- [ ] `npx hyperframes check` 에러 0
- [ ] 목표 해상도·fps·길이 일치 (`ffprobe`로 확인)
- [ ] 첫 프레임이 빈 화면이 아님 (썸네일로 쓰임)
- [ ] 오디오가 있으면 음악 전용 폴백도 렌더함

## 실제 클라이언트가 거절한 말 (이 말이 나오기 전에 잡는다)

- "너무 기본적이다: 이미지, 영상, 텍스트 순서" → 시그니처 변형, 넘겨지는 물체 ([motion-grammar.md](motion-grammar.md))
- "공간이 너무 낭비된다" → 주 피사체 60–85%
- "어떤 부분은 너무 오래 머문다" → `frozen_time.sh`
- "간격이 고르지 않다" → 행 높이·정렬선 통일
- "엘리트하지 않다, 더 세게" → 밀도는 위계로 (주 움직임 + 보조 스태거 + 3차 디테일)
- "첫 이미지가 너무 어둡다" → 밝은 오프닝
- "음악이 안 맞는다" / "효과음이 비전문적이고 거슬린다" → [audio.md](audio.md)
